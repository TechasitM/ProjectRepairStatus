ขอบเขตของโครงงาน
ลูกค้า (Frontend):
**หน้าเว็บไซต์สามารถเข้าถึงและตรวจสอบสถานะงานซ่อมปัจจุบันได้ทันที โดยใช้เพียง หมายเลขงานซ่อม หรือ หมายเลขโทรศัพท์ที่แจ้งไว้ (ไม่ต้องสมัครสมาชิกหรือใช้ Username/Password) (สอดคล้องกับทฤษฎี UX และการแก้ปัญหาใบรับซ่อมหาย )**
**สามารถแสดง Timeline สถานะการซ่อม (เช่น รับเครื่อง, กำลังซ่อม, ซ่อมเสร็จแล้ว)**
**สามารถรับ การแจ้งเตือนสถานะการอัปเดตงานซ่อม ผ่านหน้าเว็บ และ/หรือ ทางอีเมล (อัตโนมัติ) **
ร้านคอม (Backend/Admin):
**หน้าเว็บไซต์สำหรับพนักงาน/ช่างซ่อม สามารถเข้าสู่ระบบเพื่อ สร้าง/แก้ไข/ลบ รายการงานซ่อม และ อัปเดตสถานะงานซ่อม **
**มีระบบฐานข้อมูลที่สามารถจัดเก็บข้อมูลสำคัญทั้งหมด ได้แก่ ข้อมูลลูกค้า ข้อมูลเครื่องซ่อม สถานะการทำงาน ประวัติการซ่อม และข้อมูลการแจ้งเตือน **
**มีฟังก์ชันการดู รายงาน/สถิติเบื้องต้น (Report/Dashboard) เช่น อาการเสียยอดฮิต หรือจำนวนงานที่รอดำเนินการ**
