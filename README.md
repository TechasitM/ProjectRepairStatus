## 📌 บทคัดย่อ
โครงงานนี้ได้นำเสนอวัตถุประสงค์พัฒนาระบบติดตามสถานการณ์ซ่อมคอมพิวเตอร์ออนไลน์สำหรับร้านบริการซ่อม เพื่อแก้ไขปัญหาการติดตามงานซ่อมที่ล่าช้าและการจัดการข้อมูลที่ไม่เป็นระบบ การวิจัยเป็นการวิจัยเชิงพัฒนา (Research and Development: R&D) โดยใช้แนวคิดวงจรการพัฒนาระบบ (SDLC) ประกอบด้วยขั้นตอนการวิเคราะห์ ออกแบบ พัฒนา และทดสอบระบบ ระบบถูกพัฒนาในรูปแบบเว็บแอปพลิเคชัน โดยใช้ Next.js สำหรับส่วนติดต่อผู้ใช้ Laravel สำหรับส่วนประมวลผล และ MySQL สำหรับจัดเก็บฐานข้อมูล ซึ่งเชื่อมต่อกันผ่าน RESTful API ระบบรองรับผู้ใช้งาน 3 กลุ่ม ได้แก่ ลูกค้า พนักงาน และผู้ดูแลระบบ โดยลูกค้าสามารถตรวจสอบสถานะงานซ่อมผ่านหมายเลขงานหรือเบอร์โทรศัพท์ และติดตามความคืบหน้าในรูปแบบไทม์ไลน์ ผลการทดสอบพบว่าระบบสามารถทำงานได้ถูกต้องตามฟังก์ชันที่กำหนด มีความรวดเร็วในการตอบสนอง และช่วยเพิ่มประสิทธิภาพในการจัดการงานซ่อมและการให้บริการแก่ลูกค้าได้อย่างมีประสิทธิภาพ
